# 临时密码访问系统

## 📋 系统概述

营会管理系统现已实现临时密码访问控制系统，未经授权的用户需要通过密码验证或邮箱获取临时密码才能访问系统。

## 🔐 核心功能

### 1. 密码验证访问
- **自动更新**: 密码每小时自动更新一次
- **实时显示**: 界面显示密码剩余有效时间
- **强制验证**: 每次打开浏览器都需要重新验证

### 2. 邮箱获取密码
- **白名单机制**: 只有预配置的邮箱才能接收密码
- **格式验证**: 严格验证邮箱格式
- **邮件服务**: 支持配置SMTP邮件服务发送真实邮件

### 3. 访问控制
- **路由守卫**: 未登录用户无法访问任何页面
- **自动重定向**: 自动跳转到登录页面
- **会话管理**: 登录状态在浏览器会话期间有效

## ⚙️ 配置说明

### 邮箱白名单配置 (`public/json/email-whitelist.json`)

```json
{
  "whitelistedEmails": [
    "52282858@qq.com",
    "admin@camp.com",
    "manager@camp.com"
  ],
  "lastUpdated": "2025-09-16T07:00:00.000Z",
  "description": "邮箱白名单配置"
}
```

**配置方法：**
1. 编辑 `public/json/email-whitelist.json` 文件
2. 在 `whitelistedEmails` 数组中添加允许的邮箱地址
3. 更新 `lastUpdated` 字段为当前时间

## 🚀 使用方法

### 1. 启动系统
```bash
npm run dev
```

### 2. 访问系统
- 打开浏览器访问 `http://localhost:9001`
- 系统会自动跳转到登录页面

### 3. 密码登录
1. 在登录页面选择"密码登录"模式
2. 输入当前有效的临时密码
3. 点击"登录"按钮

### 4. 邮箱获取密码
1. 在登录页面选择"邮箱获取"模式
2. 输入白名单中的邮箱地址
3. 点击"发送密码"按钮
4. 查看浏览器控制台获取密码

### 5. 密码管理
```bash
# 更新密码
npm run update-password

# 查看当前密码配置
npm run view-password
```

### 6. 邮件服务管理
```bash
# 配置邮件服务
npm run setup-email

# 测试邮件配置
npm run test-email

# 查看邮件配置
npm run setup-email show
```

## 🔄 工作流程

### 普通用户访问流程
1. **打开网站** → 自动跳转到登录页面
2. **选择登录方式** → 密码登录或邮箱获取
3. **输入凭证** → 验证通过后进入系统
4. **使用系统** → 正常使用各项功能
5. **关闭浏览器** → 下次访问需要重新验证

### 密码更新流程
1. **系统定时** → 每小时自动生成新密码
2. **更新文件** → 将新密码写入 `auth.json`
3. **通知用户** → 密码过期提醒
4. **强制更新** → 旧密码失效

### 邮箱获取流程
1. **用户输入邮箱** → 选择邮箱获取模式
2. **验证白名单** → 检查邮箱是否在允许列表中
3. **格式验证** → 验证邮箱格式正确性
4. **发送密码** → 模拟发送当前密码到邮箱
5. **用户登录** → 使用收到的密码登录系统
