# 02 — 收敛管理端为统一报告中心

**What to build:** 将管理端日常入口收敛为统一报告中心，提供全部、待归属、待完善、待审核、已发布和已作废视图，并为后续导入、归属、完善和审核工单提供稳定导航。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 登录管理端后默认进入报告中心，不再默认进入业务工作台。
- [x] 报告中心具备六个主状态视图及查询区域。
- [x] Excel 导入、专业配置、推荐配置、用户和宠物仍可从独立菜单进入。
- [x] 不引入角色权限、经营分析或订单相关功能。
- [x] 原有页面在迁移期间仍可通过新壳层访问。
