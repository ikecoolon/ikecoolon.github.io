# 10 — 小程序最新发布报告阅读

**What to build:** 让用户查看一份最新发布报告的综合概览、专业检测内容、菌群层级、通俗解释、单报告内部对比和健康建议，同时正确处理缺失、未检出和无参考范围。

**Blocked by:** 05 — 专业基础资料驱动报告完善；09 — 小程序我的领取与报告列表。

**Status:** done

- [x] 用户只能查看当前发布版本，不显示版本号、纠正状态或旧版本入口。
- [x] 综合概览包含人工等级、综合分、百分位、平台评估维度及固定等级主题。
- [x] 普通指标和实际存在的菌门、菌属可继续查看专业值、范围、解释和建议。
- [x] 未检出、缺失和有值无范围按业务规则展示。
- [x] 单报告理想菌群对比使用明确标注的临时 Mock，不固化待甲方确认规则。
- [x] 不提供跨报告趋势、发布通知或统一免责声明。
