# 09 — 小程序我的领取与报告列表

**What to build:** 让用户从小程序查看宠物和报告数量、按宠物进入报告、跨宠物过滤报告，并通过扫码或手动输入领取码完成极简领取。

**Blocked by:** 01 — 统一共享 Mock 业务契约。

**Status:** done

- [x] “我的”提供宠物、报告和领取报告入口。
- [x] 宠物入口显示每只宠物的独立报告数量。
- [x] 报告入口按检测日期倒序，并支持已发布和进行中过滤。
- [x] 进行中卡片不可点击，失败、待归属和作废记录不展示。
- [x] 领取前只确认宠物、检测项目和日期，不新增、选择或编辑宠物。
- [x] 默认首页保持为待甲方确认，不固化临时方案。
