# 07 — 健康需求标签与商城 SPU 推荐

**What to build:** 让运营维护报告领域健康需求标签、标签与多个商城 SPU 的映射及主推 SPU，并演示商品实时状态变化后的候选降级。

**Blocked by:** 01 — 统一共享 Mock 业务契约；02 — 收敛管理端为统一报告中心。

**Status:** done

- [x] 一个健康需求标签可关联多个 SPU，并设置顺序、适用物种和启用状态。
- [x] 每个推荐项最多一个主推 SPU，并保留健康建议和专业依据。
- [x] 正常、零库存、下架或不存在、无候选四种情况均可演示。
- [x] 下架或不存在时按健康需求标签解析候选，零库存时保留推荐关系并给出替代品。
- [x] 不把商城分类作为健康语义，不修改商城模块源码。
