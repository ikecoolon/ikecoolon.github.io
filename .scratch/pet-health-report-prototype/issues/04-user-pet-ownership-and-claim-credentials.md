# 04 — 用户宠物归属与领取凭证

**What to build:** 让运营通过平台用户查询和线下确认完成宠物建档、报告归档、直接绑定或领取凭证生成，并能处理领取码作废重发和错误归属纠正。

**Blocked by:** 01 — 统一共享 Mock 业务契约；02 — 收敛管理端为统一报告中心。

**Status:** done

- [x] 运营可查询平台用户并后台创建或编辑宠物。
- [x] 报告可归入已有宠物或运营新建宠物。
- [x] 已注册用户可直接绑定，其他报告可生成一次性领取凭证。
- [x] 未领取凭证可作废并重新生成，旧凭证立即失效。
- [x] 错绑报告可直接更正，且保留更正前后归属、人员、时间和原因。
