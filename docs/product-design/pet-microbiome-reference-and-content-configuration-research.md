# 宠物肠道菌群参考区间与科普配置研究

> 调研日期：2026-08-26
>
> 适用范围：犬、猫粪便微生物检测报告及当前小程序设计图
>
> 目的：只确定支撑现有报告展示所需的最小配置边界，不扩张小程序页面或内容模块。

## 结论先行

1. **不存在可以直接套给所有犬猫、所有队列和所有检测方法的“某门/某属通用正常范围”。** 可以存在的是某一物种、样本类型、分析方法、计量单位和参考群体下，经验证得到的参考区间。尤其不能把 16S/宏基因组给出的相对丰度百分比，换算或套用到 qPCR 的 `log DNA/g feces` 参考区间。
2. **菌群字典只适合维护分类身份和极少量、带证据的中性科普。** “本次偏高/偏低意味着什么”“对这只宠物有什么影响”“应如何干预”都不是 taxon 的恒定属性，必须结合物种、样本、检测值、有效参考区间、分析规则及其他结果，形成单份报告结论，并由专业人员审核。
3. **不需要为每一个门或属预先填满占位文案，也不应为了页面完整而制造空内容。** 当前设计只展示本次实际检测到或报告选中的菌群；没有可靠参考区间时保留检测值，不判定“正常/偏高/偏低”；没有经审核解释时不补通用危害或建议。
4. **当前原型中“丛林角色、它是什么样、功能说明、偏低提示、偏高提示”全部放在 taxon 全局字典里，边界过宽。** 最小化后，字典只保留分类事实与一个可选的中性短说明；高低提示、分析和建议移到报告规则/审核结果。

## 1. 为什么同一个门或属不能共用一套正常范围

### 1.1 犬与猫需要分别建立范围或判定模型

犬、猫之间即使能检测到相同属，也不能据此共用参考区间。对 2,639 份犬猫粪便宏基因组的整合研究发现，犬猫共享一部分微生物物种，但同一类群中存在宿主特异的谱系适应以及代谢、耐药基因等功能差异。这说明“名称相同”并不等于宿主背景和功能完全相同。[Branck et al., 2024](https://doi.org/10.1093/ismejo/wrae201)

一个很直接的临床实例是 Texas A&M 的 qPCR 菌群失衡指数：犬、猫使用不同的目标菌组合和不同参考区间。犬面板包含 `Blautia`、`Fusobacterium`，猫面板则包含 `Bifidobacterium`、`Bacteroides`；即使两者都测量 `Faecalibacterium`、`Turicibacter`、`Peptacetobacter hiranonis`、`Streptococcus` 和 `E. coli`，给出的区间也并不完全相同，且犬的显著失衡阈值为 `DI > 2`，猫为 `DI > 1`。[Texas A&M GI Laboratory 官方说明](https://vetmed.tamu.edu/gilab/service/assays/canine-microbiota-dysbiosis-index/)

因此，原型中的 `species + taxon + min/max` 至少要继续区分犬、猫；不能设置一个无物种范围作为默认兜底。

### 1.2 健康动物内部也存在个体、饮食、年龄、品种和环境差异

- 对 286 只北美家庭健康犬的全长 16S 研究中，饮食类别、地域和体重都能解释部分菌群结构差异，作者明确提示结论外推到其他犬群仍需进一步研究。[Rojas et al., 2024](https://doi.org/10.3389/fvets.2024.1405470)
- 在相同饲养和饮食条件下比较 3 个犬种，`Fusobacterium`、`Turicibacter`、`Streptococcus` 等多个属仍存在犬种差异。[Chun et al., 2019](https://pubmed.ncbi.nlm.nih.gov/31601060/)
- 健康猫研究发现，年龄、饮食形式和居住环境都会影响“核心菌群”的组成；家庭猫和收容所猫之间存在显著差异。[Ganz et al., 2022](https://pubmed.ncbi.nlm.nih.gov/36423084/)
- 对健康犬猫粪便采样的研究中，个体身份对菌群结构的解释度高于采样位置和短时存放因素，犬、猫的个体效应分别达到 `R²=0.64` 和 `0.88`。[Tal et al., 2023](https://doi.org/10.1186/s12917-023-03842-7)

这些结果并不等于产品首期必须马上增加年龄、犬种、饮食、地区等一排配置项。更稳妥的产品结论是：**只有检测机构或已验证研究明确提供分层参考区间时，才增加相应分层；没有证据时不要用空占位符假装精细。**

### 1.3 检测方法、样本与单位不同，数值不可直接互换

16S 扩增子测序、全长 16S、宏基因组测序和目标 qPCR 测量的不是同一种量：

- 16S/宏基因组通常报告群落中的**相对丰度**；它是组成性数据，一个菌的百分比上升可能来自其他菌下降，并不等于该菌绝对数量增长。
- qPCR 可以对预定义目标作较可重复的**绝对定量**。Texas A&M 的犬猫面板按 `log DNA/g feces` 报告，不能套到百分比图表。
- 对 296 只犬同时做 qPCR 和宏基因组测序的研究显示，两种方法虽总体相关，但部分菌只能由 qPCR 检出；健康犬中某些属的测序相对丰度从未检出到很高比例，而 qPCR 的绝对量区间窄得多。[Sung et al., 2023](https://doi.org/10.3390/ani13162597)
- 对同一批健康犬分别使用 Illumina 短读长和 Oxford Nanopore 全长 16S 的直接比较发现，两套工作流在属级相对丰度上不能互换，并且会得到不同的多样性和年龄关联结论。[Polacchini et al., 2026](https://doi.org/10.1007/s11259-026-11407-w)
- 粪便、直肠拭子和肠黏膜活检捕获的群落也不能视为完全等价。[Gal et al., 2021](https://pubmed.ncbi.nlm.nih.gov/34032481/)

因此，范围的适用键不能只有“门/属 + 犬/猫”。最小情况下还要能区分**检测方案/来源模板与单位**；如果当前 Excel 自带范围，应优先保存该次报告的原始范围和单位，而不是从平台猜测。

## 2. “正常范围”与“菌群失衡指数”分别是什么

### 2.1 参考区间不是随手配置的产品阈值

美国兽医临床病理学会（ASVCP）将参考区间定义为可比较的健康参考群体中测量值的估计分布，通常覆盖中间 95%；建立新的群体参考区间时，理想情况下至少需要 120 个健康参考个体，且必须记录物种、品种、年龄、性别、地理、饲养/饮食、采样、处理和分析方法。小样本会显著增加上下限的不确定性。[ASVCP 指南](https://doi.org/10.1111/vcp.12006)、[ASVCP 官方完整版](https://www.asvcp.org/resource/resmgr/QALS/Other_Publications/RI_Guidelines_For_ASVCP_webs.pdf)

这意味着产品后台录入的上下限只能称为以下两者之一：

- **检测机构参考区间**：随 Excel/检测方案提供，并冻结到该份报告；
- **平台验证参考区间**：有明确来源、物种、方法、单位、参考群体和版本，经专业人员批准后使用。

不满足这些条件的数字不应对用户称为“通用正常范围”或“理想范围”。

### 2.2 犬猫 DI 是特定 qPCR 面板的分类算法，不是所有菌平均后的通用分数

犬 DI 的原始研究用 95 只健康犬与 106 只组织学确认慢性炎症性肠病犬建立和验证模型；面板测量总菌量及 7 个目标菌群，再由最近质心分类器计算单一数值。以 0 为阈值区分健康犬和慢性肠病犬时，灵敏度 74%、特异度 95%。[AlShawaqfeh et al., 2017](https://doi.org/10.1093/femsec/fix136)

猫 DI 的研究使用 80 只健康猫与 68 只慢性肠病猫，目标菌组合与犬并不相同；阈值 0 的综合灵敏度为 77%、特异度为 96%。[Sung et al., 2022](https://doi.org/10.1177/1098612X221077876)

要特别区分：

- 单菌的“参考区间”描述健康参考群体中的测量分布；
- DI 的 `0`、`2` 或 `1` 是该专用算法的**判定阈值/解释分层**；
- 这两个概念都不能从当前页面上一组百分比范围自行推导。

### 2.3 DI 仍有明确局限

- 它是对菌群整体偏移的指标，不单独诊断某一种疾病，也不直接证明失衡是疾病的原因。
- 犬阈值 0 的灵敏度 74%、猫为 77%，意味着一部分慢性肠病动物仍可能落在 0 以下；猫研究也明确提出应与炎症等其他生物标志物和临床信息结合。
- qPCR 面板只能识别预先选定的目标，不能发现未知或未纳入的菌；宏基因组覆盖更广，但目前个体级临床解释又缺少统一验证和参考区间。
- 抗生素、质子泵抑制剂和饮食等都可能改变结果。Texas A&M 要求结合单菌结果，特别是 `P. hiranonis`，并考虑近期药物和饮食。[Texas A&M GI Laboratory](https://vetmed.tamu.edu/gilab/service/assays/canine-microbiota-dysbiosis-index/)
- 伴侣动物粪菌移植临床共识认为，经过验证的犬猫 DI 可用于供体筛查；但不推荐用尚未验证且没有个体解释标准的下一代测序结果判断供体“正常/异常”。这是共识中的低质量证据建议，不能被扩大成“所有 NGS 都无用”。[Companion Animal FMT Consortium clinical guidelines](https://pmc.ncbi.nlm.nih.gov/articles/PMC13251538/)
- AAHA 营养与体重管理指南也提示，微生物组检测的临床应用仍有限，尤其应警惕由检测直接导向补充剂销售的做法。[AAHA 指南](https://www.aaha.org/resources/2021-aaha-nutrition-and-weight-management-guidelines/microbiome-prebiotics-postbiotics/)

## 3. 菌群功能说明能否放进 taxon 全局字典

### 3.1 可以作为共性配置的内容

以下内容是分类身份或带范围的科普事实，可以全局复用：

| 内容 | 配置建议 |
| --- | --- |
| 稳定编码、中文展示名、学名、分类层级、父级 | 全局 taxon 字典；它们用于搜索、分类树和页面标题 |
| 新旧学名/同义名 | 全局别名；例如 `Clostridium hiranonis` 已常写作 `Peptacetobacter hiranonis` |
| 一句中性短说明 | 可选；必须标注适用物种或“跨物种”、证据来源和专业审核状态 |
| 已证实的特定机制 | 仅在证据足够、层级足够精确时写成中性事实，并限定物种；例如犬研究支持 `P. hiranonis` 与初级胆汁酸转化为次级胆汁酸密切相关，但仍不等于单凭丰度即可给个体下治疗结论。[Correa Lopes et al., 2024](https://doi.org/10.3390/ani14020216) |

中性科普应使用“研究发现……相关/参与……”而不是“好菌、坏菌、核心保护者、过多就挤占其他菌”等确定性标签。16S 属级结果通常不能提供菌株功能或实际代谢活性；犬猫大规模宏基因组研究也发现宿主特异的菌株和功能差异，因此不能把某属的一句话扩张为所有物种、所有菌株的固定作用。[Branck et al., 2024](https://doi.org/10.1093/ismejo/wrae201)

### 3.2 必须结合单份报告并由专业人员审核的内容

下列内容不得由 taxon 字典直接输出：

- “本次正常、偏高、偏低、未检出”的状态；
- “为什么会这样”“会造成什么风险”的解释；
- 当前宠物的健康结论、综合评价、风险级别；
- 饮食、益生菌、药物、复检或就医建议；
- 与其他菌、代谢物、多样性指标的组合解释；
- 商品推荐理由。

这些结论至少依赖以下运行时上下文：报告物种、样本类型、检测方案/平台、单位、检测值、该次有效参考区间、其他结果、近期用药/饮食信息（如果报告有）、规则版本和审核后的最终文案。

例如“某属偏高会挤占其他保护性菌属”是一条生态与因果判断，不能仅凭属名和单项百分比成立；“补充某种益生菌”更属于干预建议，不能由字典自动推出。当前截图中 `Collinsella` 下的解释以及“分析/总体建议”都应属于**这份报告的审核结果**，不属于 `Collinsella` 全局定义。

## 4. 对当前设计图的最小配置边界

相关设计图：

- `docs/product-design/img/微信图片_20260825163609_86_525.jpg`：门/属检测数值与正常范围对比；
- `docs/product-design/img/微信图片_20260825163611_87_525.jpg`：菌门详情、属级检测卡、分析和总体建议。

### 4.1 不需要“每个菌一个占位符”

推荐删除“每个 taxon 科普字段都必须使用 `{pet} {theme} {taxon} {value} {status}`”这一隐含要求。

- 分类名称、父级、学名和中性科普本身不需要占位符。
- 检测值和范围已经在数值卡片中单独显示，不必再次塞进科普句子。
- 设计图中的“莎莎的雨林中，药草与苔藓（放线菌门）——略显繁茂”是组合后的完整展示文案：宠物昵称和等级主题来自报告，场景短称来自菌群科普，菌群名称来自分类字典，末尾状态词来自检测值相对有效参考范围的判定。
- 偏低、正常、偏高状态可以映射为全局可配置的中性场景词，但不为每个门/属重复配置，也不能把它当成健康影响、风险程度或干预建议。

### 4.2 建议保留的最小后台配置

#### A. 菌群分类字典

只保留：

- 稳定编码；
- 中文展示名与学名；
- 层级（门/属）；
- 父级；
- 别名（可选）；
- 场景短称（可选，仅用于形成完整报告场景描述草稿）；
- 一段中性说明（可选，带来源和审核状态）。

不再把“丛林角色、它是什么样、功能说明、主要工作、偏低提示、偏高提示”设为每个 taxon 的拆分字段。报告审核只处理最终完整句子。

#### B. 参考区间

只在有明确来源时配置，并按检测方案成套维护，不让运营按“物种 × 指标”逐行新建。每个参考范围方案最少记录：

- 明确适用的一种或多种物种；
- 检测方案；
- 结果单位/计量方式；
- 全套检测项/taxon 的下限、上限（允许单侧）；
- 专业依据、版本和生效状态。

年龄、品种、饮食、地区等不应先建一排空字段；将来检测机构确实提供分层范围时再扩展。Excel 自带范围优先，并连同方法和单位冻结到报告版本。多个物种只有在专业证据确认相同范围时才能共用方案；新增物种默认不继承，可复制既有方案后修订差异，或直接批量导入专业方提供的整套范围。

#### C. 单份报告内容

报告保存并审核：

- 检测值、有效参考区间与判定状态；
- 当前结果的通俗解释；
- 分析结论；
- 总体建议。

这些字段只为设计图中实际出现的结果生成，不要求所有字典菌都拥有一份内容。

### 4.3 小程序渲染规则

| 设计图内容 | 数据归属 | 最小行为 |
| --- | --- | --- |
| 门/属名称与所属关系 | taxon 字典 | 按本次报告实际项目展示 |
| 检测值 | 报告检测事实 | 原单位展示，不推算 |
| 正常范围条 | 报告冻结的有效参考区间 | 只有方法、物种、单位匹配时展示 |
| 正常/偏高/偏低颜色 | 报告判定结果 | 无有效范围则不显示状态色 |
| 一句雨林/森林比喻 | 报告宠物与等级主题 + 菌群场景短称 + 相对范围状态词 | 组合为完整文案；状态词只作中性场景修辞 |
| 属级解释、分析、总体建议 | 单份报告审核内容 | 只展示本次已有内容 |
| 字典中没有检测结果的菌 | 无 | 不创建空卡片、不显示“待补充”占位 |

这套边界已经足够支撑现有小程序的两个菌群页面，不需要新增“菌群机制库、症状库、干预方案库、按品种范围库”等新模块。

## 5. 对现有原型内容的具体判断

1. `dictionary-data-service.js` 中当前按犬猫和门配置的百分比范围只能作为演示数据，除非甲方能提供对应检测机构、方法、单位和参考群体证据；不能把它标为医学通用正常范围。
2. `Bacteroides属`、`Collinsella属` 等全局的“过多会挤占其他菌”“缺乏益友时会失衡”等文案，混合了科普、状态解释和因果判断，建议从全局 taxon 知识中移出。
3. “有助于分解碳水化合物并调节胆汁酸”等功能句，如果继续保留，应由专业人员确认具体物种、分类层级和证据；对属级结果应使用中性、有限措辞。
4. 没有专业内容的门/属不必设置空白占位符。小程序按报告实际结果裁剪，正好符合“不新增内容，只支撑设计图展示”的目标。
