# 宠物健康报告开放问题

以下事项尚未形成产品决策，不得直接作为实现要求。已形成的临时口径只用于演示原型，并在条目内注明。

## 待甲方确认

### 检测项目与报告类型

- 当前产品是否长期只提供宠物微生物组检测，还是需要建立可扩展的检测项目或报告类型。
- 如果未来增加其他检测项目，它们是否分别拥有 Excel 模板、检测指标、分析规则和预设报告模块。

当前临时口径为内部决定（ADR-0023）：平台只支持微生物组报告，不建设可配置报告类型。甲方尚未确认，在确认前不能把“只支持一种报告”或“首期即建设多报告类型配置”作为对外承诺的实现要求。

### 小程序默认首页

- 登录后默认进入独立“首页”，还是自动打开检测日期最新的一份已发布报告。
- 无已发布报告以及存在多只宠物、多份报告时采用何种默认落点。

当前临时口径为内部决定：保留独立首页作为固定登录落点，即使只有一只宠物和一份报告也不自动跳过；首页最多展示三只宠物和最近三份已发布报告。已确认“我的”只提供宠物入口，用户从宠物详情查看简单资料和已发布历史报告。

### 必备报告模块的最低非空标准

- 综合概览与有效检测结果是必备核心模块，当前临时标准为：综合概览具备已关联宠物、明确报告物种、人工等级和综合分；有效检测结果至少包含一项有效数值或明确未检出；三个首页摘要指标允许个别缺失。该标准是否为最终标准需甲方确认。
- 分析模块（各菌门的“分析”与“建议”）在规则有命中但未经人工确认、或确认后为空时，是否阻断发布，尚未确认。

已确认单个检测项缺失可以发布，任一必备模块完全没有可展示内容时阻断发布。

### 商品推荐的用户端呈现

- 商品推荐在小程序中出现在对应菌门的“建议”区域内、固定区域还是独立页面。
- 一个推荐位展示主推与关联商品的数量、卡片或列表形式，以及“查看更多”的方式。
- 管理端报告工作台中商品配置放在独立的“商品推荐”模块，还是并入各菌门的“分析与建议”卡片。

当前临时口径：管理端保留独立“商品推荐”模块，按菌门列出建议摘要与商品槽。已确认的配置边界不受此问题影响：商品推荐为单份报告中的运营人工配置，每条建议最多一个主推 SPU 和三个有序关联 SPU，不使用健康需求标签、推荐映射、自动排序、自动替换或推荐算法；管理端使用可分页搜索、按状态筛选的商品选择界面。

### 参考范围的来源

- 检测机构或甲方是否会按物种、检测方案和单位提供整套正常下限与正常上限；若提供，以何种文件形式、多久更新一次。
- 若首期没有可用参考范围，是否接受以下表现：菌群对比模块隐藏、菌门与菌属卡片不显示正常范围、分析规则只依据机构给出的 `vs AVG notice`。

已核对三份真实 Excel（harley / oscar / riley）均不含任何参考范围。已确认对比与状态判断只使用正常下限和正常上限，图表坐标起点不等同于真实下限，平台不维护理想目标值（ADR-0024）。设计图中的 2%–8%、12%–20%、15%–30%、40%–65% 等范围目前没有数据来源。

### 平台评估维度与首页漂浮气泡

- 设计图综合概览中“情绪 / 免疫”两项之外，插画上还有四个漂浮气泡（其中一个标注“VIT B 中等”）；它们是另外的平台评估维度、菌群数值还是纯装饰。
- 平台评估维度是固定的两项，还是需要可配置的维度列表（名称、图标、数值、标签、展示位置）。

当前临时口径：综合评定只提供“情绪 / 免疫”两个人工填写字段，首页气泡由前端取前四个有结果的菌门百分比填充。

### 首页摘要指标的数据来源

- Alpha 多样性、均匀度和丰富度三项固定摘要指标由谁提供：检测机构另行给出、平台按属级丰度计算，还是审核人员人工填写。
- 若由平台计算，采用何种算法与聚合口径。

已确认三项摘要指标固定、审核人员不能逐份替换、缺失时原位置显示“暂无有效结果”。三份真实 Excel 均不含这三项数据。

### Excel 原始菌群记录的聚合口径

- 同一菌属在一份文件中出现 1–13 行时如何合并为一个属级有效结果；class / order / family 列全部为占位值，是否可以忽略。
- 属级结果如何聚合为菌门值。
- 文件内 `Your sample (%)` 合计为 100.01%、120.80%、134.97% 各不相同，合计偏离 100% 的含义是什么。

在口径确认前，原型继续使用 Mock 数据演示，不实现真实聚合。

### `vs AVG notice` 的判断基准

- `high` / `low` 相对的“AVG”是机构内部什么样本群的均值，是否区分物种、年龄或检测方案。
- `-` 表示在均值范围内，还是表示未做评估。

当前临时口径：`-` 的菌属仍是有效检测结果并正常展示，实验室比较状态记为“未标注”，不触发依赖 `high` / `low` 的分析规则。

### 分析规则的目标层级

- 分析规则针对菌属、菌门，还是两者都允许。
- 属级命中的分析与建议是否归入所属菌门的“分析”与“建议”区域展示。

当前临时口径：规则目标字段允许选择菌门或菌属，属级命中归入所属菌门。

### Excel 文件与送检记录的配对方式

- 检测机构能否在文件名或文件内提供样本编号、送检编号或宠物标识；若能，采用何种约定。
- 若不能，是否接受只允许从送检记录发起定向导入，并由运营人工核对归属。

三份真实 Excel 均不含宠物、样本、报告编号、检测日期或用户信息，唯一可用信息是文件名（如 `harley_final_microbiome_report.xlsx`）。重复检测文件的判定只能依赖送检记录侧的编号。
