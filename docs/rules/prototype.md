# 原型维护

## 目录与链接

静态原型放在 `docs/.vuepress/public/prototypes/<端>/<能力>/`。一个能力可以有多个页面、脚本和资源；后续需求继续更新该能力的当前版本。端名和能力名使用稳定的小写英文目录名。

每篇 PRD 在正文顶部链接本轮涉及的具体入口，并在 `prototypeEntries` 中登记相同路径。站点会按端和能力汇总这些入口及相关 PRD。移动目录时同步检查页面内导航和相对资源路径。

## 评审内容

原型展示页面结构、接近真实的模拟数据和可操作流程；业务规则留在 PRD。关键操作需呈现必要的正常、空态、校验和失败反馈。只模拟目标端可控制的界面与交互，不把系统原生界面伪装成可定制页面。

修改后检查入口能打开、脚本和资源能加载、关键交互能走通，并同步修正与 PRD 不一致之处。
