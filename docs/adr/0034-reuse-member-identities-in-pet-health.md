# 宠物健康模块复用平台会员身份

宠物健康模块不建立独立客户实体，而是通过会员模块 API 查询、校验和发起最小创建，并在自身模块内维护宠物及用户宠物关联。未注册客户以必填手机号和可选姓名发起创建，同一身份域内同手机号已有用户直接复用；创建后基础资料只读，具备相应权限时进入现有会员管理修改。这样可以扩展宠物关系能力，同时不复制或改写会员资料、等级、积分、余额等原平台基础功能。

现有跨模块 API 尚缺最小创建、分页及部分身份投影，真实实现需补接口，由健康模块提供宠物/报告聚合；本次静态原型不修改真实平台。首次报告访问须通过既有已验证手机号登录取得对应会员身份，普通微信登录不能保证复用；历史绑定冲突不自动合并，列入真实联调边界。
