# 在现有商城小程序内承载健康报告

宠物健康报告作为现有商城小程序同一 AppID 下的新增模块实现，不新建独立报告小程序，也不做跨小程序跳转。这样可以复用商城已有登录态、商品详情、购物车、订单、支付和退款能力，避免重复建设交易后端；代价是商城小程序前端需要增加健康报告入口、页面、路由/分包、返回路径和商品详情衔接，并对既有微信认证、商户权限、AppID 绑定、安全参数及支付退款链路完成核验与回归联调。

## Consequences

- 小程序启动/登录后的全局默认首页调整为健康报告原型的当前宠物页（健康报告首页），主导航按原型为「首页」「我的」。
- 健康报告前端不得持有商户 API 私钥、APIv3 密钥或其他支付安全材料；这些继续由商城支付后端管理。
- 可购推荐商品在同一小程序内进入既有商城商品详情；首期不记录报告来源的商品点击、加购、订单或支付归因。
- 项目估期包含商城小程序前端二次开发和完整交易链路回归，不重复估算购物车、订单、支付与退款后端的新建工作。
