# 「菌群科普」本轮锁定管理端壳、预览状态与身份只读

邱燕萍在群聊确认「一起 允许改」：本轮「菌群科普」UE **可以同时改原型**的两处——（1）修好「全局场景词设置」的界面壳，（2）用户端预览支持判定状态切换。产品设计只改文档，不改 HTML/JS/CSS。本 ADR 只锁定下列交互；未列入的项见 `docs/product-design/open-questions.md` Q14，不得写成终稿。

「全局场景词设置」必须是完整的右侧 Drawer（遮罩 + 面板）或与其他管理端弹窗一致的居中 Modal。当前损坏的 `ant-drawer-without-styles` 不是有效产品形态，不得沿用。全局场景词只配置偏低 / 正常 / 偏高三套中性修辞，不为每个门或属重复配置。

用户端预览必须能在偏低 / 正常 / 偏高 / 无范围之间切换。切到「无范围」时不追加全局场景词，与「没有有效参考范围就不拼场景后缀」一致（ADR-0020、ADR-0024）。该切换只服务编辑预览，不改真实报告检测值。

学名 / 拉丁名是菌群分类单元的身份字段，只在「专业基础资料」分类树编辑；「菌群科普」页只读展示，不得在本页改身份。

完整度须让「未齐 / 未填」可见（筛选或徽章均可）。「已填 / 齐」对应哪些必填字段仍待定，不得把当前原型的任意字段集写成齐套标准。

下列仍待定，本 ADR 不拍板：已发布报告读实时科普还是发布冻结；齐套必填字段集合；提示条是否做成临床 / 风险措辞的硬性拦截（内容原则仍遵循 ADR-0020 中性科普）；菌属卡片标签用「外观 / 功能」还是「像什么 / 能力」。
