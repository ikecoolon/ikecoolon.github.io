# 报告编制与审核采用可组合权限

管理端将登记、导入、完善、分析确认和提交审核划入编制权限，将待审核时的审核修订、退回和发布划入审核权限，两组权限可分别授予，也可由同一后台账号同时拥有。这样可以复用现有平台权限体系并支持不同规模的运营团队，同时不增加强制提交人与审核人分离的业务规则。专业基础资料、参考范围方案与菌群科普另由专业资料权限维护，不等于编制权限；报告工作台不因编制或审核权限开放平台方案编辑。详见 ADR-0037。

仅有编制权限的人员能够完成提交前的菌门确认；待审核的普通编制修改须由原提交人撤回后进行，审核人员仍可留痕修订。后台操作员身份与被服务的平台用户身份分开，撤回按提交者身份判断，双权限账号可审核自己提交的报告。
