# 「指标/参考范围」按专业资料方案维护，工作台不改平台方案

平台参考范围只在管理端「指标/参考范围」由具备专业资料权限的人员成套维护；报告工作台只为本份报告确认或驳回导入范围，不编辑平台方案。方案绑定已知检测模板（`templateId` 从已知模板列表选择，禁止自由文本）和明确适用物种。同一（已知模板, 物种）至多一个**启用**方案：一个方案勾选多个物种时，对其中每个物种都占用该名额；启用冲突时拦截，须先停用原方案，不按时间或版本隐式择优。草稿与停用方案可并存。范围项从专业基础资料可搜索选择指标或菌群，选定后类型与分类层级只读回填，禁止手改。每项只允许同时填写正常下限和正常上限，禁止单侧、禁止理想目标字段。方案不要求「参考依据说明」；若界面保留该字段，仅为可选审计，不作为保存或启用条件。

编辑表支持行上移 / 下移和「在此下方插入」；拖拽排序不是 v1 必做。方案内范围项顺序只方便专业人员编排，不驱动用户端对比顺序；对比按本份有效检测结果及其在菌群分类树中的门 / 属组织。编辑表预期有吸顶表头和行号。

引导：保留整方案复制为草稿；另可把另一方案的范围项复制进当前编辑表（追加后由操作人删改，同一指标保存前只留一行）。可选按菌门字典预填空行（只带指标身份，不带上下限）。草稿允许未填完的空行；启用时纳入匹配的项必须双侧有效且下限小于上限。

有效范围来源仍为：工作台确认可用的导入范围 → 该（模板, 物种）唯一启用方案 → 空。驳回导入范围后回落到平台方案或空；没有任何有效范围时对比模块隐藏。不允许在单份报告手填第三套范围。当前真实 Excel 不含导入范围，确认 / 驳回是前瞻能力，不挡 v1 出报告。详见 ADR-0024。
