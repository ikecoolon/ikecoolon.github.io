# 送检登记拆开承接门店与检测机构，并按类型区分登记主按钮

登记送检不再使用合并的「检测机构 / 来源」单字段。承接门店表示承接该案的商户门店，两种送检类型均必填。检测机构表示出具 Excel 的实验室：本店送检通常与门店同时填写；客户自带报告时门店必填、检测机构可选（选择已有实验室或自由文本）。列表分列展示两列。这样门店履约与实验室出数可以分开记录，客户自带报告也不必硬填实验室。

本店送检主按钮仍为「确认登记」，登记后不自动打开文件选择。客户自带报告主按钮为「登记并导入」：先完成登记并生成待导入结果记录，再立即打开该行的文件选择；若运营取消选择，记录已经存在，提示「已登记，可稍后在该行导入」，这不是失败。两条路径都是先登记再在该行导入，不做列表级批量导入，也不设待归属。

关键词搜索覆盖送检 ID、样本编号、手机号、宠物名；登记成功后高亮并滚到新行。样本编号仍可选。重复判定只在同一检测机构内，空样本编号不参与；平台送检 ID 与报告号全局唯一。详见 ADR-0018。
