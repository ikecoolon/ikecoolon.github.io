# 参考范围只采用报告导入或平台配置

有效参考范围优先采用工作台确认可用的报告导入范围，缺失或被驳回时自动匹配「指标/参考范围」中该（已知模板, 报告物种）的唯一启用方案，两者都没有则保持为空；系统不判断导入范围的专业有效性，也不允许在单份报告中人工填写第三种范围。驳回导入范围后只能回落到平台方案或空，对比模块在没有任何有效范围时隐藏。当前真实 Excel 不含导入范围，确认 / 驳回是前瞻能力，不挡 v1 出报告。未发布工作版本打开时自动采用最新平台匹配结果并触发相关内容重新分析确认，已发布版本继续冻结原有效范围。平台方案的编辑、启用唯一性与范围项编排见 ADR-0037。该决策取代 ADR-0009 中允许审核人员直接修订最终范围的部分。
