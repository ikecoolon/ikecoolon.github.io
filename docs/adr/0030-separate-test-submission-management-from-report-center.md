# 送检管理与报告中心分开

送检记录与报告是前后相接但生命周期不同的业务对象：送检管理负责登记后到成功生成报告前的履约队列，报告中心只负责已经生成报告后的归属、完善、审核、发布和追溯。运营已经需要持续跟进“已送检但尚未拿到报告”和导入异常，因此触发 ADR-0021 预留的独立流程条件；成功导入后送检记录统一完成为“已生成报告”，不继续复制报告状态。

## Consequences

- 管理端在同一“检测与报告”分组下提供“送检管理”和“报告中心”两个入口。
- 登记送检和从该送检记录发起的导入结果 / 重新导入归入送检管理；不做列表级无预登记批量导入，也不设独立 Excel 导入页。报告中心不再承接报告生成前动作。
- 两个对象保持一对一关联并允许双向跳转，但各自列表只展示自身生命周期状态。
- 界面不把待归属作为可操作状态。送检字段与登记主按钮见 ADR-0036。
