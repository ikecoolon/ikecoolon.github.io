# 管理端逐页样式修复（2026-09-06）

用户反馈部分页面样式异常后重新逐页复现。本记录不沿用上一轮仅报告中心/工作台的交付结论。

## 初始证据与根因

| 页面/状态 | 观察 | 已定位原因 |
| --- | --- | --- |
| 参考范围列表 | 状态直接显示 span 标签文本 | BasicTable 默认转义，页面未提供显式 render |
| 分析规则列表 | 同上 | 同上 |
| 专业基础资料三分类 | 类型标签与树缩进显示 HTML/nbsp | 同上；缩进应为节点样式而不是文本实体 |
| 菌群科普、规则编辑/测试、报告工作台、登记弹窗 | 输入框/选择框无边框，编辑内容像普通文字 | 公共控件仅覆盖 rondo-input，遗漏仍使用的 ant-input 和弹窗外于页面容器的情况 |
| 专业基础资料新增弹窗 | 单行输入框高 80px | modal 下 rondo-input 与 textarea 误共用 min-height |
| 窄屏列表搜索 | 两列压缩输入区域 | 公共搜索网格缺少窄屏单列规则 |
| 专业基础资料 | 重复标题和新增入口 | 页头与 BasicTable 同时生成相同动作 |
| 用户详情 | 显示 published 内部状态码 | 未使用中文状态展示映射 |

初始探针：参考范围/资料/规则分别有 2/19/9 个字面 HTML 单元格；菌群科普 5 个可见字段 borderTopWidth 为 0px。首轮表格回归 10 项失败，显式 render 修复后 16 项通过。默认文本转义保留，业务数据不作为任意 HTML 解析。
